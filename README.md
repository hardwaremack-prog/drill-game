# Drill Game

"Deep Drill," a digging game. Drive your rig underground, haul ore back up, and upgrade as you go deeper.

![Drill Game screenshot](<Drill Game - screenshot.png>)

## How to play

- Move and dig with the **arrow keys** or **WASD**
- Watch your **depth**, **fuel**, **hull** and **cargo** gauges
- Return to the surface to sell your cargo and refuel
- Spend your earnings on **upgrades** to dig deeper and carry more
- A log keeps track of what you've found

## Run it

Download `drill_game-final-b1.html` and open it in your web browser. No install, no account, nothing to set up.
